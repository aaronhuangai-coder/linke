    Agent 配置

    示例配置

    {
  "serverUrl": "http://localhost:3000",
  "deviceId": "my-macbook",
  "backupJobs": [
    { "name": "documents", "sourcePath": "/Users/ah/Documents" }
  ],
  "excludePatterns": ["*.tmp", "node_modules"],
  "scheduleSeconds": 3600
}

    Launchd Dry-Run 命令

    node src/agent.js launchd-dry-run --config config.json

    备份预检 Dry-Run 命令

    node src/agent.js backup-preflight-dry-run --source ./important-docs --exclude "*.tmp" --exclude node_modules

    ⚠️ 备份预检 dry-run 只扫描 sourcePath — 不创建快照、不复制文件、不写入 metadata 或仓库元数据

    ⚠️ 未安装到系统 — 仅生成 plist 预览（dry-run），不调用 launchctl，不写入 ~/Library/LaunchAgents

    NAS Dry-Run 命令

    node src/agent.js nas-dry-run --config config.json

    ⚠️ NAS dry-run 仅生成计划预览 — 不连接 NAS、不发起网络请求、不写入任何远端存储
